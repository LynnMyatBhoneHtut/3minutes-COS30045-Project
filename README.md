## About
A simple one-page data story built with D3.js v7:
- **Q1** – How have hospitalisations changed? (line chart)
- **Q2** – Which road users are growing fastest? (indexed line chart, 2011 = 100)
- **Q3, Q4** – Planned (age and sex; states and First Nations rates)

## Data
BITRE (2023), *Hospitalised injury*, from the AIHW National Hospital Morbidity Database.
Processed in KNIME and exported as CSV files to `data/`.
